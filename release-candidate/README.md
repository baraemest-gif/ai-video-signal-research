# Pre-DOI Release Candidate

Status: **HOLD — NOT FOR PUBLICATION AS A DOI RELEASE**

This directory stages the release package structure without asserting that the research object is ready for archival publication.

## Purpose

The candidate package exists to prove that the first AI Video Signal research release can be rebuilt from a known state, validated before publication, and archived without depending on the live buyer-facing website.

## Candidate components

Required before publication:

- immutable provider dataset in CSV
- equivalent provider dataset in JSON
- methodology snapshot
- evidence/source manifest
- release manifest
- changelog
- citation metadata
- explicit license/usage terms
- reproducibility instructions
- checksums for released files where practical
