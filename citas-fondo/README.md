# Citas Madrid - Fondo v2

App Android que comprueba la conexión técnica a la sede oficial con pantalla bloqueada mediante una alarma INEXACTA cada 15 minutos. Android puede retrasarla. HTTP 200 no equivale a citas disponibles. No usa NIE, certificados ni contraseñas y no reserva citas. La reserva requiere el portal oficial desbloqueado. Termina el 27/10/2026.
